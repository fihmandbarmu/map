# Map Explorer (Google Maps Clone)

A web-based mapping application that allows users to view maps, search for global locations, and center the map on their device's current location.

## Features

- **Interactive Map:** Pan and zoom smoothly using mouse or touch controls.
- **Location Search:** Geocoding powered by the OpenStreetMap Nominatim API.
- **Geolocation:** Centering capability using the browser's native Geolocation API.
- **Responsive Layout:** Sidebar interface layered over a full-bleed map viewport.

## Tech Stack

- **HTML5:** Semantic structure.
- **CSS3:** Flexbox layout and basic UI styling.
- **JavaScript (ES6):** Async API calls and dynamic DOM manipulation.
- **Leaflet.js:** Open-source JavaScript library for mobile-friendly interactive maps.
- **OpenStreetMap:** Map tile provider and geocoding service.

## Getting Started

1. Clone or download all four project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` directly in any web browser.
3. *Note:* For Geolocation to work, the page should ideally be served over an `https://` connection or from `localhost` using a local web server (e.g., Live Server extension in VS Code).
